|---|---|---|
| `playfair-*.woff2` | Playfair Display (вариативный, 400–900, прямой и курсив) | SIL Open Font License 1.1 |
| `geologica-*.woff2` | Geologica (вариативный, 100–900) | SIL Open Font License 1.1 |
| `plexmono-*.woff2` | IBM Plex Mono 400 | SIL Open Font License 1.1 |
