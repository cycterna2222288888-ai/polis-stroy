# polis-stroy

Сайт строительной компании ООО "Полис" (Москва). Заказчик — Коля. Язык сайта: русский.

- Контент и структура старого сайта: `content/site-content.md` — источник правды по текстам, контактам, реквизитам, категориям каталога.
- Страницы: главная (о компании + бренды-партнёры), услуги, каталог с категориями, контакты.
- Фирменный цвет со старого сайта: `#99d6eb`.
- Сайт статичный, без бэкенда, если не сказано иное. Адаптивная вёрстка (mobile-first), быстрый, с SEO-метаданными (title, description, og:*).
- Не выдумывать факты о компании (проекты, цены, отзывы) — только то, что есть в content/.
